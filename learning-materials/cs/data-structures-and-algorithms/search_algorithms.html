Model solution
public static int findIndex(String[] arr, String target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i].equals(target)) {
            return i;
        }
    }
    return -1;
}

Linear search

Your findIndex method probably used a loop. The loop probably started at the first item in the array and moved forward through the list, checking each item to see if it is what you are searching for.

When you search through an a collection of items sequentially (in order, one at a time), it is called a linear search. This is useful when there is no particular order to the content being searched.

Check Your Understanding 1

State the worst-case time complexity of your method, in Big O notation, where n represents the length of the input array.

The loop can run a maximum of n times, once for each item. The work per iteration does not depend on the array size, so the worst-case time complexity is O(n).

Practice 2

Could you use a similar strategy to find a word in an English dictionary? Describe your strategy to a partner.

Yes. Because dictionary words are alphabetically ordered, open near the middle and compare that word with the target. Ignore the half where the target cannot be, then repeat with the remaining half until you find the word or have no possibilities left.

Suppose we wanted to search through an alphabetically ordered array of Strings for the word “jump.” How could we ask a question that would tell us which half contains the word, if it exists?

Find the middle word and compare it alphabetically with “jump.” If the middle word comes before “jump,” search the right half. If it comes after “jump,” search the left half.

Find the middle word of the right half and compare it with “jump.” If that middle word comes before “jump,” keep the right part of that half; otherwise keep the left part.

Practice 13

The binary search repeats a set of steps until the value is found or there are no items left. Write the steps for one iteration. No code is required.

  1. Find the middle of the current search segment.
  2. Compare the middle value with the target.
  3. If the middle is less than the target, search the right half.
  4. If the middle is greater than the target, search the left half.
  5. If equal, return the middle index.
  6. If no values remain, return -1.

Practice 14 — Coding

Create binarySearch(int[] arr, int x) for an ascending array. Return the index of x, or -1 if it is absent.

public static int binarySearch(int[] arr, int x) {
    int start = 0;
    int end = arr.length - 1;

    while (start <= end) {
        int mid = (start + end) / 2;

        if (arr[mid] == x) {
            return mid;
        } else if (arr[mid] < x) {
            start = mid + 1;
        } else {
            end = mid - 1;
        }
    }

    return -1;
}

Extension Challenge

Binary search can work for many types of values as long as the values can be put in sorted order. Strings can be sorted alphabetically, integers from least to greatest, and objects can potentially be sorted using one of their fields.

Extension — Model solution

Use Java's Comparable<T> interface so objects can compare themselves.

public static <T extends Comparable<T>>
int binarySearch(ArrayList<T> list, T target) {

    int start = 0;
    int end = list.size() - 1;

    while (start <= end) {
        int mid = (start + end) / 2;
        int comparison = list.get(mid).compareTo(target);

        if (comparison == 0) {
            return mid;
        } else if (comparison < 0) {
            start = mid + 1;
        } else {
            end = mid - 1;
        }
    }
    return -1;
}
